## 🚀 Tilmaamaha Isticmaalka (Quick Start Guide)

Wax kasta waxaa loo habeeyay qaab fudud oo 1-guji ah (`.bat` files) si aadan mar kasta terminal koodh ugu qorin:

### 1️⃣ Sida Loo Kiciyo Portal-ka Shaqada (Local Web UI)
Galka mashruuca dhexdiisa ku dhufo:
```bash
start_portal.bat
```
* Tani waxay si toos ah kuugu furaysaa bogga: **`http://localhost:5050`**
* Waxaad sidoo kale taleefankaaga kaga geli kartaa: **`http://192.168.1.73:5050`** (haddii aad ku xidhan tahay Wi-Fi-ga guriga).

### 2️⃣ Sida Loo Baadho Shaqooyinka Maanta (5 Curated Jobs)
Haddii aad rabto inaad shaqooyin cusub ka soo saarto Indeed & Glassdoor:
```bash
run_indeed_jobs.bat
```
* Wuxuu soo saarayaa 5-ta shaqo ee maanta ugu sarreeya Edmonton & Remote Canada, wuxuuna ku keydinayaa `jobs_today.html` iyo `data_folder/output/cached_jobs.json`.

### 3️⃣ Sida Loogu Dhiibo Vercel (Live Cloud URL)
Haddii aad doonaysid inaad internet-ka oo dhan ka gasho telefoonka adigoo guriga ka maqan:
```bash
deploy_to_vercel.bat
```
* Wuxuu si toos ah koodhka ugu dhiibayaa Vercel Serverless, wuxuuna ku siinayaa Live Link joogto ah (e.g., `https://auto-jobs-applier-aih-awk-live.vercel.app`).

### 4️⃣ Sida Docker Loogu Dhex Kiciyo (Container Mode)
Haddii aad isticmaalayso Docker Desktop:
```bash
docker compose up -d
```
* Wuxuu ku shaqaynayaa deegaan madax-bannaan (Isolated Container) isagoo isticmaalaya Gunicorn WSGI server.
